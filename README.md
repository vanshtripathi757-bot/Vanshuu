# Vanshu — Software Developer Portfolio

A responsive, dark, cinematic personal portfolio built with plain HTML, CSS, and JavaScript. Designed as a beginner-friendly starting point that can be edited entirely through GitHub's mobile website.

## Preview

This project is hosted in the repository: https://github.com/vanshtripathi757-bot/Vanshuu

## Features

- Responsive layout for phones, tablets, and desktop
- Dark visual theme with blue/violet accents
- Hero section, project cards, about section, skills, learning roadmap, and contact CTA
- Lightweight CSS animation and no external dependencies
- Single-file starter, easy to understand and customize

## Run locally

Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Find **Pages** in the sidebar or settings menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. Wait for GitHub Pages to publish the site. The Pages settings screen will show the published URL.

## Customize before sharing

- Replace the sample project cards with projects you have actually built.
- Update the skill list to reflect your current experience honestly.
- Add your preferred contact method if you want to be contacted.
- Check every link on a phone before sharing the portfolio publicly.
